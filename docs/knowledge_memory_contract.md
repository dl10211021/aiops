# OpsCore 知识库与 AI 记忆固定契约

本契约用于防止知识库和记忆系统继续无边界扩张。后续开发只围绕这里的固定逻辑补齐体验、接口和测试。

## 1. 知识库负责什么

知识库负责保存“可信资料”和“可审计证据”，不是保存每次对话的临时上下文。

固定内容范围：

- 原始文档：巡检 SOP、故障处理记录、系统架构说明、变更规范、日志样例、表格、图片、HTML。
- AI 候选 Wiki：辅助模型基于原始资料生成的候选 Markdown。
- 正式 Wiki：人工审核通过后进入 `wiki/articles/` 的知识。
- Obsidian 图谱：基于正式 Wiki、候选 Wiki、`[[双链]]` 和内容提及生成的关系图。

固定流程：

1. 资料入库：保存原始资料，只读留底。
2. AI 编译：辅助模型生成候选 Wiki，不直接污染正式知识。
3. 审核入库：人工确认事实、来源、风险和可复用性。
4. 检索追溯：离线搜索和 Obsidian 图谱追溯证据。

不做：

- 不把所有会话流水直接写入知识库。
- 不绕过人工审核直接进入正式知识。
- 不引入额外数据库保存图谱，图谱必须可由 Vault 文件重建。

## 2. AI 记忆负责什么

AI 记忆负责保存“成功经验”和“用户确认的偏好/事实”，不是替代知识库。

固定内容范围：

- 用户点赞确认的回答经验。
- 人工确认可复用的会话结论。
- 资产画像、主机经验、资产类型经验。
- 错误反馈、冲突记录、过期复核记录。

固定流程：

1. 浏览记忆：查看文件记忆。
2. 写入与检索：新建、搜索、验证上下文。
3. 审计治理：处理冲突、差评、过期、版本和脱敏。

不做：

- 差评内容不进入长期正向记忆。
- 未验证的推断不写成事实记忆。
- 记忆不能替代实时巡检，使用前必须结合当前资产验证。

## 3. 知识库和记忆如何联动

- 知识库提供稳定事实、文档证据和 Obsidian 双链关系。
- 记忆提供用户偏好、资产经验和成功操作路径。
- 会话回答时先看当前资产实时状态，再参考记忆和知识库。
- 记忆可以引用知识库路径；知识库不反向吸收未经审核的记忆。

## 4. 后续开发边界

允许继续做：

- 完善上传、编译、审核、搜索、图谱体验。
- 完善记忆写入、搜索、反馈、冲突治理、版本审计。
- 完善测试和错误提示。

暂不做：

- 多租户知识隔离。
- 外部图数据库。
- 无限画板入口。
- 未审核内容自动入库。
