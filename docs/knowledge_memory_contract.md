# OpsCore RAG 知识库与 AI 记忆定稿契约

本契约用于给知识库和记忆系统收口，防止继续无边界扩展。后续只做修复、体验打磨、测试补齐和性能优化，不再新增大模块。

## 1. 最终产品定位

OpsCore 只保留两条能力线：

- RAG 知识库：保存资料、检索证据、让会话回答可追溯。
- AI 记忆：保存用户确认的成功经验、偏好和纠错记录，让同类会话更聪明。

两者都不能替代当前资产的实时巡检结果。AI 回答必须优先看当前会话真实证据，再参考 RAG 和记忆。

## 2. RAG 知识库负责什么

RAG 知识库负责“资料和证据”，不负责保存每次对话流水。

固定内容范围：

- 原始资料：文档、表格、巡检报告、故障记录、SOP、架构说明、日志样例、HTML 报告。
- AI 摘要：辅助模型或主模型基于原始资料生成的中文摘要、实体、风险、建议和关键词。
- RAG 检索：按问题、资产、故障、命令、结论等关键词召回证据。
- 关系图谱：展示资料、资产、故障、Runbook、会话结论之间的连接。

固定闭环：

1. 上传资料：保存原始文件，保留可审计来源。
2. 建立检索：优先做 RAG 检索；向量不可用时保留原文检索兜底。
3. 会话引用：AI 回答前自动检索相关资料，并注入已脱敏证据。
4. 回答展示：AI 回复下方显示引用来源，区分 RAG 资料和长期记忆。
5. 证据回查：点击 RAG 引用，跳回知识库检索对应资料证据。

不做：

- 不再把界面做成复杂 Wiki 流程。
- 不要求用户理解 Vault、Candidate、Article 这类内部概念。
- 不把所有会话流水自动写入知识库。
- 不引入外部图数据库；关系图谱必须能从本地资料重建。

## 3. AI 记忆负责什么

AI 记忆负责“经验和偏好”，不负责保存资料原文。

固定内容范围：

- 用户点赞的高质量回答和成功处理经验。
- 用户确认的偏好、注意事项、资产经验。
- 画像、会话结论、成功工具路径的压缩摘要。
- 用户点踩的纠错记录和避免项。
- 记忆版本、冲突、脱敏和审计记录。

固定闭环：

1. 会话中引用：AI 回答前召回相关长期记忆。
2. 回答后反馈：用户点赞表示可沉淀；点踩表示不作为成功经验。
3. 压缩保存：思维模型优先压缩成功经验；未配置辅助模型时主模型接管。
4. 使用前验证：记忆只能作为经验提示，不能替代当前资产真实检查。
5. 记忆治理：可查看、编辑、删除、脱敏和处理冲突。

不做：

- 点踩内容不进入正向长期记忆。
- 未验证的推断不写成事实。
- 不把记忆当作知识库资料原文。
- 不因为“看起来相关”就跳过实时巡检。

## 4. 会话回答的最终规则

会话回答必须满足：

- 左侧输出能看到 AI 最终报告。
- 右侧思维链能按轮次和时间追踪工具执行过程。
- AI 回答下方能看到引用来源。
- RAG 引用能跳回知识库查证据。
- 长期记忆引用能跳到记忆管理。
- 引用内容必须脱敏，不能把密码、Token、密钥直接暴露给模型或页面。

## 5. UI 最终边界

知识库页面只保留简单入口：

- 资料入库
- RAG 检索
- 关系图谱
- AI 记忆

不再增加复杂流程、审核队列、过多状态页或多套命名。内部实现可以保留兼容字段，但用户看到的名称必须中文、简单、直观。

## 6. 后续只允许做的事情

允许继续做：

- 修 bug。
- 简化文案。
- 提升检索准确性。
- 优化图谱视觉。
- 补测试。
- 改善错误提示。
- 性能和安全加固。

不再继续做：

- 新知识库体系。
- 新 Wiki 流程。
- 新数据库/图数据库。
- 新审核系统。
- 无限画板入口。
- 多租户知识隔离。
- 未经用户确认的自动资料迁移。

## 7. 最小验收标准

当前阶段达到以下标准即可收口：

- 资料可以上传并被 RAG/原文检索命中。
- 会话回答能自动引用 RAG 资料和长期记忆。
- 引用来源能在回答下方看见。
- 点击引用能回查资料或记忆。
- 点赞/点踩能影响记忆沉淀策略。
- 敏感字段默认脱敏。
- `python scripts/preflight.py --check-git` 通过。
