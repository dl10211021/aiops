# Legacy Archive

This directory keeps historical helper scripts and tool configuration that are no longer part of the active OpsCore product surface.

Active product code remains in `api/`, `core/`, `connections/`, `frontend/`, `scripts/`, `tests/`, and deployment/runtime entrypoints at the repository root.

Do not extend files here for new product work. If a historical script becomes useful again, move the needed behavior into an owned module or maintained script first.
